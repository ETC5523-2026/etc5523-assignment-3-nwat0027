### Overview of Deliverables

This repository contains a complete Quarto website showcase translating
complex epidemiological modeling from @zachreson2022 across blog
communication format.

### Intended audience

Engaged citizens, international travellers, and community members who
want to understand when international borders can reopen safely, why
quarantine leaks occur despite strict protocols, and what high
vaccination coverage achieves in practice.
